## Phase 1 — audit findings

Labels: **V** = verified in this audit; **I** = inference from verified data; **H** = hypothesis that needs account access to confirm.

### Deployment and crawl state

- **V** Production matches `main` (d44712a): all 32 files under `website/` compared by SHA-256 against the live site (HTML normalized only for Cloudflare email obfuscation): 32/32 identical.
- **V** `robots.txt` allows all and declares the sitemap; the sitemap lists 15 URLs; every sitemap page returns 200, self-canonicalizes, has exactly one H1, and has no `noindex`. `404.html` is `noindex, follow`.
- **V** No broken internal links, missing in-page anchors, or inconsistent phone links in `website/` (one phone target site-wide: `tel:+18182138798`).
- **V** JSON-LD: every page references the single firm entity `https://thousandoaksinjury.com/#firm` with the same name, address, and phone. No `hasMap` (needs the Google Business Profile map URL; see the human tasks below).
- **V** `https://www.thousandoaksinjury.com/` still returns Cloudflare **522** (checked 2026-10-17). This needs Cloudflare account access; it can't be fixed in this repository.

### Conversion defects

- **V, P0** `/car-accident-lawyer/` (the primary PI page) shows two contradictory notices under the case-review form on the live site: *"Online submission is being connected for the redesign preview. Please call or email the firm to send a case inquiry."* and *"Secure online submission is available."* Cause: the status element used `id="form-note"`, which `assets/city-pages.js` doesn't recognize (`#form-integration-note`/`#form-status`), so the stale notice was never replaced.
- **V** Seven other pages carried stale fallback text in their HTML (*"will be enabled only after a secure form endpoint is identified and tested"*, RU equivalent). JavaScript replaces it for most users, but crawlers and no-JS users see it.
- **V, P0** On a first mobile visit (390×844), the consent banner covered **310 px (37%)** of the screen, hiding the hero's call and case-review buttons. The sticky bar read only "CALL" / "FREE CASE REVIEW", with no visible number.
- **V** The consent UI was English-only, including on `/ru/`.

### Measurement reliability

- **V** GA4 `G-2QSCB196HW` loads **only after a visitor clicks Accept** (opt-in). `phone_click` and `generate_lead` are sent only for consenting visitors. GA4 therefore undercounts calls and leads by an unknown, likely large, share; treat it as a lower bound, never as a lead count.
- **V** The authoritative lead record is the intake email sent by `functions/api/case-review.js` (it includes the submitting page URL, query string included) plus the phone log. A `phone_click` is a tap, not a completed call.
- No tracking IDs were added or changed. The consent default (opt-in) was intentionally left as is; changing it is a legal and privacy decision for the firm.

### Why non-PI searches appear (business lawyer: 502 impressions / 0 clicks)

- **V** Site copy has no business-law content: "business" appears only incidentally (roads, evidence, attorney biography).
- **I/H** Plausible sources, not verified: (1) the Google Business Profile, whose website is this domain and whose description and category (as observed 2026-10-05) lead with corporate, business-litigation, contract and related work, plus a generic "Law firm" category; (2) the firm entity's `sameAs` link to `www.savostyanovlaw.com`, a general-practice site. The `sameAs` link correctly describes the same firm and was **not** changed.
- To confirm: in Search Console, filter Query = "business lawyer" and open the **Pages** and **Search appearance** tabs. If the impressions land on `/` with brand-like behavior, the GBP is the likely driver.

### Ranking context (from the issue's GSC data)

`car accident lawyer thousand oaks` ≈ 25.6 and `car accident attorney thousand oaks` ≈ 57.5 average position. The car-accident page had strong general content but almost no Thousand Oaks-specific substance and no links to the nearby city or related practice pages.
